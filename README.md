# Encryption Algorithm RGR
Программа «Encryption Algorithm RGR» предназначена для шифрования и дешифрования текстовых данных и файлов с использованием трёх криптографических алгоритмов: RSA, Эль-Гамаля и WAKE.

Программа предоставляет пользователю следующие возможности: выбор алгоритма шифрования из трех доступных модулей; генерацию ключевых пар и ключей шифрования для каждого алгоритма; шифрование и дешифрование произвольных текстовых и бинарных файлов; шифрование и дешифрование текста непосредственно через консоль; представление зашифрованных данных в hex-формате при консольном вводе/выводе.

<i>Программа реализована на языке C++ (стандарт C++17) с использованием динамически подключаемых библиотек (.so / .dll). Работает в среде операционных систем Linux и Windows. Для запуска и корректного функционирования программы требуется не менее 5 МБ свободного дискового пространства и не менее 32 МБ оперативной памяти.</i>

# Описание операций
Основные функции программы «Encryption Algorithm RGR» включают генерацию ключей, шифрование и дешифрование данных. 

При запуске приложения запрашивается пароль доступа. Введённое значение сравнивается с эталоном из файла password.hash. При вводе неверного пароля выводится сообщение об ошибке, и программа завершает работу. 

После успешного прохождения авторизации пользователь попадает в главное меню программы, где доступен выбор криптографического алгоритма: <i>RSA, Эль-Гамаль, WAKE, Выход</i>.

После выбора одного из алгоритмов программа динамически загружает соответствующий модуль и выводит подменю с операциями: <i>Сгенерировать ключ, Зашифровать текст, Расшифровать текст, Зашифровать файл, Расшифровать файл, Назад.</i> 

 «Сгенерировать ключ» программа вызывает функцию plugin_generate_key(), которая формирует необходимую ключевую пару или ключ для выбранного алгоритма и сохраняет его в указанный файл или выводит на экран.
